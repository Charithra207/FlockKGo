# OpenStreetMap spot data

`osm_cafes.json` and `osm_nature.json` are extracts of OpenStreetMap data for
Karnataka, made by `import_osm_spots.py fetch`.

Data © OpenStreetMap contributors, available under the Open Database License
(ODbL): https://www.openstreetmap.org/copyright

Keep the "© OpenStreetMap contributors" credit visible on the site (footer and
map). Spots that came from OSM are marked `source = "osm"` in the database.
